OBIETTIVO
Aggiornare le skill `.windsurf/skills/agent-execution-mandate/SKILL.md` e `.windsurf/skills/idle-village-task/SKILL.md` affinché gli agenti sappiano come usare i frozen kits e come aggiornare trusted docs quando toccano componenti certificati/frozen.

FILE TARGET
1. `.windsurf/skills/agent-execution-mandate/SKILL.md`
2. `.windsurf/skills/idle-village-task/SKILL.md`

OPERAZIONI DA ESEGUIRE
1. In `agent-execution-mandate/SKILL.md`:
   - Aggiungi un punto al flusso di esecuzione: se il task modifica un componente `trusted`/`frozen`, l'agent deve aggiornare il `*_trusted.md` corrispondente e `COMPONENT_MASTER_INDEX.md` prima di contrassegnare il task come completo.
   - Cita `.windsurf/rules/30-frozen-kits.md` e `.windsurf/rules/40-documentation-governance.md` come riferimenti obbligatori.
2. In `idle-village-task/SKILL.md`:
   - Aggiungi una sezione "Frozen Kits" in Core requirements:
     - Usare i kit esportati da `@/ui/idleVillage/frozen/kits`.
     - Creare nuovi kit tramite `npm run freeze:kit <KitName>`.
     - Aggiungere `hub` metadata per le pagine di test.
     - Mantenere `TestHub` generato da `KIT_REGISTRY`.
   - Aggiungi il requisito: modifiche a componenti `trusted`/`frozen` richiedono aggiornamento `*_trusted.md` + `COMPONENT_MASTER_INDEX.md`.
3. Mantieni lo stile e la struttura esistenti.

OPERAZIONI VIETATE
- Non creare nuovi rule file.
- Non modificare `KIT_REGISTRY`, `TestHub` o `COMPONENT_MASTER_INDEX.md`.
- Non toccare le skill strategist/coordinator (sono in GOV-003).
