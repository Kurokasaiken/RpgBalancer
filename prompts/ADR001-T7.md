# ADR001-T7 — Deprecate C1 quest runtime + migration guide

## Context
Part of Quest Engine Reconciliation (ADR-001). Phase T7 deprecates the old C1 quest runtime, creates a migration guide for any remaining C1 usage, and archives legacy code. This phase is documentation-focused after the C2 engine is verified in T6.

## Objectives
- Deprecate C1 quest runtime with clear deprecation notices

- Archive legacy C1 code to `archive/` directory
- Update ADR-001 trusted doc with deprecation status
