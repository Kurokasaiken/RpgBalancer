# ADR001-T4 — Purge Math.random() from quest engine

## Context
Part of Quest Engine Reconciliation (ADR-001). Phase T4 removes all uses of `Math.random()` from the quest engine, replacing them with the deterministic `RngService` created in T1. This ensures reproducible quest outcomes and proper seed management.

## Objectives
- Remove all `Math.random()` calls from quest engine code
- Replace with `RngService` methods (`createRng`, `deriveSeed`, `rollOutcome`)
- Add CI lint gate to prevent future `Math.random()` usage
- Verify quest engine behavior remains deterministic

## Scope

### Files to Modify
- `src/engine/game/idleVillage/` — Replace `Math.random()` with `RngService`
- `src/engine/quest/` — Replace `Math.random()` with `RngService`
- `.eslintrc.js` or equivalent — Add lint rule to ban `Math.random()`

### Files to Create
- (None — refactoring existing code)

### Out of Scope
- Quest engine runtime changes (deferred to T6)
- Telemetry integration (deferred to T6)
- UI component updates (deferred to T5)

## Guardrails

### Invariants
- **Determinism**: All randomization must use seeded `RngService`, never `Math.random()`
- **Config-first**: Any probability/threshold values must be in config, not hardcoded
- **Persistence**: Seeds must be managed via `PersistenceService` where applicable
- **i18n**: Any user-facing strings must use `idleVillage` namespace

### Constraints
- Do not change quest logic — only replace randomization mechanism
- Ensure all `Math.random()` calls are replaced (grep search required)
- Add CI gate to prevent regression

Search entire codebase for `Math.random()` usage:
