Sei un agente Windsurf: consulta le skill `agent-execution-mandate` e `idle-village-task` prima di iniziare, segui i mandati, completa la safeguard suite ed esegui le consegne Kanban.

INVARIANTI

- `.windsurf/rules/30-frozen-kits.md` (dopo GOV-001).
- `.windsurf/rules/40-documentation-governance.md` (dopo GOV-002).

OBIETTIVO
Creare `scripts/validate-systems.ts` e i relativi unit tests come deterministic executable gate che verifichi l'allineamento tra `COMPONENT_MASTER_INDEX.md`, `KIT_REGISTRY` e i `*_trusted.md` files, e registrarlo come npm script `validate:systems`.

FILE TARGET
1. `scripts/validate-systems.ts` (new)
2. `tests/unit/harness/validateSystems.test.ts` (new)
3. `package.json` (update scripts section)

OPERAZIONI DA ESEGUIRE
1. Crea `scripts/validate-systems.ts` come script CLI `tsx` con:
   - Leggere `src/ui/idleVillage/frozen/registry.ts` (`KIT_REGISTRY`) tramite import statico (Node 20 + tsx) o parse robusto.
   - Leggere `src/docs/docs/idle_village/COMPONENT_MASTER_INDEX.md` e parsare la tabella componenti.
   - Per ogni kit `certified`/`draft` in `KIT_REGISTRY`:
     - esiste una riga in `COMPONENT_MASTER_INDEX.md` con lo stesso `kitId` o nome;
     - se `docPath` è specificato, il file esiste;
     - se `status === 'certified'`, esiste `contract` e `certManifestPath` (o logga warning).
   - Per ogni riga in `COMPONENT_MASTER_INDEX.md`:
     - il `Source of Truth` linkato esiste;
     - lo `status` è uno di `draft`, `candidate`, `trusted`, `frozen`, `deprecated`.
   - Stampare un report in console con eventuali errori/warning e exit code `1` se ci sono errori critici, `0` se tutto OK.
   - Non modificare `COMPONENT_MASTER_INDEX.md` o `KIT_REGISTRY`.
2. Crea `tests/unit/harness/validateSystems.test.ts` con almeno 3 test che verifichino:
   - kit con `docPath` mancante produce errore;
   - componente in master index con source of truth inesistente produce errore;
   - stato non canonico produce errore.
3. Aggiungi in `package.json` > `scripts`:
   - `"validate:systems": "tsx scripts/validate-systems.ts"`
4. Assicurati che il tipo TypeScript e le dipendenze siano corrette.

OPERAZIONI VIETATE
- Non modificare `COMPONENT_MASTER_INDEX.md` o `KIT_REGISTRY`.
- Non creare nuovi trusted doc.
- Non scrivere logica che modifichi i file di governance.
