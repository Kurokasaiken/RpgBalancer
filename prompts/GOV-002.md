AGENT
GOV-002 – Add Documentation Governance rule to `.windsurf/rules/`

ISTRUZIONI AGENTE
Sei un agente Windsurf: consulta le skill `agent-execution-mandate` e `idle-village-task` prima di iniziare, segui i mandati, completa la safeguard suite ed esegui le consegne Kanban.

INVARIANTI
- `.windsurf/rules/00-project-invariants.md` (documentation section, shared baseline).
- `src/docs/docs/DOCUMENTATION_GOVERNANCE.md` (policy ufficiale, trusted docs, MASTER_PLAN).
- `src/docs/docs/plans/systems_governance_alignment_plan.md` §4.A.2.

OBIETTIVO
Registrare il sistema **Documentation Governance** nel layer condiviso `.windsurf/rules/` in modo che ogni modifica a un componente `trusted`/`frozen` obblighi l'agent a aggiornare la doc trusted e l'indice master.

FILE TARGET
1. `.windsurf/rules/40-documentation-governance.md` (new)

OPERAZIONI DA ESEGUIRE
1. Crea `.windsurf/rules/40-documentation-governance.md` con:
   - `trigger: always_on`.
   - Header: `# Documentation Governance Invariants`.
   - Contenuto derivato da `src/docs/docs/DOCUMENTATION_GOVERNANCE.md` e `systems_governance_alignment_plan.md` §4.A.2:
     - Ogni componente/contratto `trusted`/`frozen` deve avere una sola `*_trusted.md` doc e una riga in `COMPONENT_MASTER_INDEX.md`.
     - Modificare behavior, visual contract, runtime contract, source-of-truth usage o binding runtime di un componente `trusted`/`frozen` richiede l'aggiornamento della doc trusted, del master index e la produzione di evidence.
     - Nessuna chiusura documentale senza verifica runtime.
     - Nessuna duplicazione di contratti in documenti generali.
     - Stati canonici: `draft`, `candidate`, `trusted`, `frozen`, `deprecated`.
     - Le eccezioni al vincolo kit devono essere tracciate in `src/docs/docs/idle_village/EXCEPTIONS.md`.
2. Non modificare `00-project-invariants.md` (gestito da GOV-001).
3. Verifica coerenza di formattazione con gli altri `.windsurf/rules/*.md`.

OPERAZIONI VIETATE
- Non modificare `src/docs/docs/DOCUMENTATION_GOVERNANCE.md` in questo task.
- Non aggiornare `COMPONENT_MASTER_INDEX.md` (sarà GOV-006).
- Non creare nuovi trusted doc.
- Non modificare `00-project-invariants.md`.

ASSUNZIONI
- `DOCUMENTATION_GOVERNANCE.md` contiene già la policy completa.
- `COMPONENT_MASTER_INDEX.md` esiste in `src/docs/docs/idle_village/`.
- GOV-001 e GOV-002 sono indipendenti; possono essere eseguiti in parallelo.
