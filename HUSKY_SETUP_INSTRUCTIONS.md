# Husky Pre-commit Hook — ACTIVE (PLAN-122 T-4)

> **Status 2026-11-15:** this document previously described a *planned* minimal-slice
> hook that was never installed. That setup is superseded: a real hook now exists
> at `.husky/pre-commit` and is active (`core.hooksPath=.husky/_`, `prepare: husky
> install` already wired in `package.json`).

## What the hook does

`.husky/pre-commit` runs, in order:

1. `npm run lint:staged` — lint-staged: `npx eslint --cache --fix --max-warnings=55`
   on the configured globs (`src/ui/idleVillage/**`, `src/engine/game/idleVillage/**`,
   `src/ui/styleLab/!(physics|physicsLab)/**`). `--fix` may rewrite staged files.
2. `npm run governance:check -- --staged` — orchestrated invariant checks
   (`scripts/governance/governanceCheck.ts`). **Staged-scoped:** only checks whose
   check→globs map intersects `git diff --cached` run; per-check timeout 30s.

A non-zero exit from either step blocks the commit.

## Known caveat (2026-11-15)

Some orchestrated checks scan their whole target surface (e.g. `foreground:lint`
scans `scripts/`, `trusted:check` verifies the sealed trust-set). A commit can
therefore be blocked by **pre-existing violations outside your staged files**.
At hook activation, `foreground:lint` flags 2 committed violations in
`scripts/hud-real/_tmp-*.mjs` and `trusted:check` reports trust-set drift —
both pre-date the hook. Fix them or report them; do not silence the check.

## Escape hatches (emergencies only — enforcement is the point)

- `HUSKY=0 git commit …` — husky skips all hooks (documented env var).
- `git commit --no-verify` — bypasses git hooks entirely.

## Troubleshooting

```bash
# hook not running?
git config core.hooksPath        # → .husky/_
ls .husky/_/pre-commit           # husky shim must exist
ls -l .husky/pre-commit          # must be executable

# debug a run
sh -x .husky/pre-commit
HUSKY=2 git commit …             # husky debug output
```

## Regenerating husky internals

`.husky/_` is generated by `husky install` (runs via `prepare` on
`npm install`) and is git-ignored. Fresh checkouts get it automatically.
