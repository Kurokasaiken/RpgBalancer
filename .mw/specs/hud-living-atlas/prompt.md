# HUD Living Atlas — Generation Prompt

Derived from `art_direction_plan.md` (Prismatic Wanderlust) and the R-075 audit direction "Living Atlas". Kept under the 77 CLIP-token gate; the canonical prompt is the `text` block below.

## Canonical positive prompt

```text
Fantasy game screen, full-bleed painterly world map edge to edge: lush valley, golden thatch village, azure river, alpine peaks. Deep teal shadows, solar white light, oil impasto. Tiny edge HUD: bronze medallions left, parchment tag top right, glyphs bottom. No bars, no text.
```

## Negative prompt

text, watermark, signature, letters, numbers, blurry, low quality, cartoon, 3d render, modern ui, flat design, dashboard, top bar, side panel, dark ribbon, window frame, grey, brown, mud, grim, sci-fi, symmetry, weather icon, health bar, progress bar, buttons

## Notes

- Target 1536×1024 (horizontal Wilderness composition).
- Map must read as protagonist (~90% of frame); HUD objects must be small and edge-docked.
- One solar highlight per object; no repeated gold borders.
