### Appendix

#### Methodology

This stress testing follows the Phase 10.5 methodology:

1. **Single-Stat Archetypes**: Each stat increased by +25 × weight points
2. **Pair-Stat Archetypes**: All C(n,2) combinations tested with +25 points each
3. **Baseline Comparison**: Win rates compared against baseline archetype
4. **Synergy Calculation**: `pairScore / expectedScore` where expectedScore is average of single stat win rates
5. **Threshold Classification**: OP > 1.15, Weak < 0.95
