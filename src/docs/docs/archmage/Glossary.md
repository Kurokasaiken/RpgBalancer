# Archmage Glossary

| Term | Description | Notes |
| --- | --- | --- |
| Mental Palace | Infinite inner domain where spells are housed, trained, and negotiated. | Core setting; referenced across gameplay docs. |
| Spell-Creature | Semi-sentient fragment of a multidimensional entity; acts as both spell and companion. | Each has needs, moods, evolution tree. |
| Veronome | Magical signature of a magus that allows other beings to summon them. | Drives risky reciprocity events. |
| Transcendence Path | Meta-progression route (Alchemy, Necromancy, Angelic, Demonology, Abstract Mind). | Determines NG+ modifiers. |
| Wanderlust DNA | Art direction pillars combining Wilderness & Empire aesthetics with split rendering. | Source: `src/docs/docs/plans/art_direction_plan.md`. |
| Gilded Observatory | Current default UI theme/classes used across Balancer interfaces. | Temporary shell until Wanderlust UI kit ships. |
| PersistenceService | Async storage layer (`src/shared/persistence/PersistenceService.ts`) required for all saves/loads. | Mentioned in TechnicalDirection. |
| Weight-Based Creator Pattern | Config-first balancing method where every entity is defined as `{value, weight}` ticks. | Mandatory for new systems. |

_Add new entries whenever terminology is formalized in feature specs._
