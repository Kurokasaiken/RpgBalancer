not filigree.

## Visual DNA

| Element | Value |
| --- | --- |
| **Silhouette** | Three-tier: backward-swept flattened cranial shield (never lateral), slender feminine figure on anatomical heels, heavy low train + floating shawl halo |
| **Movement** | Glides, poses, unfurls, drifts — heavy low train vs jellyfish-delayed shawl |
| **Materials** | ivory grafts / champagne-gold seams / prismatic veils (Nm kit) + ruby flesh, dark sinew, pale skin (Vicissitudine) |
| **Colors** | noble ivory / deep ruby / champagne gold / prismatic iridescence / deep teal shadows |

## Visual Inspiration

- **Creature Design:** H.R. Giger anatomical unease (no industrial tubing), Cephalaspis cranial geometry, Elesh Norn as anti-reference
- **Material:** carved scrimshaw ivory, mother-of-pearl nacre, René Lalique glass, ruby gemstone
- **Movement:** jellyfish drift (shawl), sovereign posing (figure)
- **Marks:** Neoranga-style engraved geometry on ivory (groove color TBD: gold or ruby)

## Rejected Directions

- **Elesh Norn clone:** blade crown, white armor over red flesh formula
- **Biomechanical priestess:** tubes, gears, implants
- **Lateral shield:** the plate must sweep backward, never protrude sideways
- **Costume logic:** heels/train/shawl are anatomy, not clothing or jewelry
- **Gore version:** muscle reads as gemstone; the burned hand is a designed scar

## Coherence Test
