## Visual review (agent witness, 2026-10-21)

Crouched moth-faced insectoid ghoul in a dark teal crystal court:
filament antennae, layered mouth flaps, one huge faceted
blue-violet eye vs one small pale eye, clusters of iridescent
compound eye-pits on shoulder/chest/thigh/forearm, small eye-rows
down one arm, pale gaunt skin. Reads clearly as a low-rank sensory
servant.

**Deviations flagged:** iridescent facet clusters diffuse prismatic
over solid skin — **resolved by Director ruling 2026-10-21**:
low-affinity hosts carry *gouged prismatic wounds*; moth mouth /
eye clusters = **Nm donor-DNA upgrade (ichthyic)** per the same
ruling — the host was too weak, so the Nm borrowed better anatomy.
