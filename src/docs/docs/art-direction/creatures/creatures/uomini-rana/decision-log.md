# Uomini-Rana — Decision Log

## v0.1.0

**Decision:** Concept card reconstructed and filed in the Creature IP
Development System with working name "uomini-rana" (Director, 2026-10-12).

**Reason:** The characteristics were defined in the discussion of
22 August and needed a canonical home; the race is NOT declared canonical
in Wanderlust: Triumph — status stays `draft`.

**Key specs locked in this version:**

- Legs ~2.5× torso length; torso measured shoulders→hips, legs measured
  hips→sole (newer Director spec, added to avoid ambiguity with total
  body length).
- Three clawed digits per hand; narrow elongated three-toed
  amphibian/reptilian feet.
- Purple skin `#7D00B9`, amber pustules, marked wrinkles.
- Large irregular dorsal spines (porcupine/echidna; *The Village*
  atmosphere) — silhouette-defining but not a hedgehog-man.
- True monastic robe + hood (not rags), two primitive spears.
- Environment: basalt desert, ancient ruins.
- Style: Split-Rendering Wanderlust; references Jordu Schell,
  Iain McCaig, Ruan Jia, Jaime Jones, Jeff Easley.

**Addendum (2026-10-12, same-day correction):** the prompt's Style
section initially read generically ("painterly fantasy with visible
matter"). Director correction: the agreed style is the canonical
Split-Rendering with THICK impasto brushstrokes (bibbia art-direction
§10 — "impasto pennellate spesse invariato"). `prompt.md` updated:
clean sculptural face/eyes vs thick Jaime Jones oil impasto on skin,
spines, cloth and basalt; NO LIST extended with thin glazes,
airbrushed gradients, smooth digital paint.

**Iteration (2026-10-12, Director spec):** legs even longer and
thinner — spec raised from ~2.5× to ~3× torso, stick-thin; eyes now
milky/opaque (clouded pale). Updated `prompt.md`, `identity.md`,
`reference-card.md` accordingly.

**Open decisions:**

- **Family:** none of the four existing families admit humanoid anatomy
  or sapient culture — needs a new family (e.g. sapient peoples) or an
  explicit out-of-family ruling.
- **Canonical name:** "uomini-rana" is temporary.
- **World tier, evolution path, animation grammar, player behavior:**
  all TBD.
- **Reference image:** the exploratory visual from the original session
  is not preserved; the first generated image must pass the Coherence
  Test in `reference-card.md`.
