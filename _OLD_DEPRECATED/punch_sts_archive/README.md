# Punch Club & STS Archive

## Overview
This directory contains archived documentation and assets from the Punch Club and STS (Slay the Spire) modules that were removed from the active codebase on 2026-02-11 as part of the CLN-01 through CLN-05 cleanup operations.

## What Was Removed
- **UI Components**: Punch Club landing pages, STS simulators, and related React components
- **Configuration**: All Punch Club and STS configuration files, presets, and schemas
- **Analytics**: Punch Club telemetry and STS performance reporting systems
- **Tests**: Unit tests, integration tests, and Playwright specs for both modules
- **Documentation**: Strategy guides, implementation plans, and operational documentation
- **Scripts**: CLI tools and automation scripts for both modules

## Archive Contents
The original files have been moved here to preserve historical context while removing them from the active development workspace.

## Status
- **Punch Club**: Decommissioned - no longer supported or maintained
- **STS**: Decommissioned - no longer supported or maintained

## Migration Notes
- No shared utilities were identified that required migration to other modules
- All functionality was self-contained within the respective modules
- The remaining codebase (Idle Village, Balancer) continues to function independently
